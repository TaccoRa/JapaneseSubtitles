## AI Ideas

- Split `SubtitleManager` into smaller components for subtitle parsing/cleaning,
  remote GitHub search, episode caching/downloading, and geometry calculation. It
  currently owns too many workflows, which makes performance bugs harder to isolate.
- Add cancellation tokens or generation checks to every background worker path:
  automatic ruby generation, remote downloads, episode preparation, OCR, and Anki
  stroke synchronization. Some already have generation checks; make this consistent.
- Split `requirements.txt` into runtime and development requirements later. The
  current file mixes app dependencies, benchmarks, Selenium experiments, and pytest.
- Add versions or schema tags to remote search cache files. This will make it safer
  to change search heuristics without accidentally reusing stale cached JSON.
- Consider a lightweight task queue abstraction for background work so throttling
  and shutdown behavior are handled in one place. This is mainly for maintainability
  and shutdown safety, not a guaranteed performance improvement.
- `SubtitleManager` has some extracted helpers/modules, but it still owns parsing,
  cleaning, remote search, episode maps, downloads, ruby generation, and geometry.
- Add a small Anki preview/test area in Advanced Settings that shows the effective
  tags and lookup form for a sample selected word and sentence.
- Add a `Copy diagnostics bundle` button to the Performance tab. Include the current
  subtitle file, episode, debug state, cache counts, and queue sizes.
- Add a local-config cleanup/migration action that removes stale keys from
  `config.local.json`.
- Add tests for multiple occurrences in one subtitle sentence, for example selecting
  `勉強` when only one occurrence is used as `勉強した`.
- Add a compact Anki failure-details popup showing whether a failure came from
  AnkiConnect, model fields, translation, duplicates, or media routing.
- Add a subtitle difficulty heatmap and an episode review queue for unknown words.

## Fixed

- Unhandled Tk callback and background-thread errors now show a message box with the
  log path instead of only printing or failing silently.
- The annotation matcher handles purpose forms such as `俺を 殺しに` from `殺す`
  without re-enabling broad derived-noun matching such as `動き` from `動く`.
- Exact annotation phrases can bridge subtitle spaces, so a database entry such as
  `分かり合える` can win over a partial `分かる` match in `分かり 合える`.
- Spaced verb tails no longer make an entire phrase known from the first verb alone.
- Exact kana/non-kanji phrases such as `だから` are covered by phrase annotation
  even when the tokenizer splits them.
- Popup Ctrl+C and popup add hotkeys are more robust after focus changes or missed
  key-release events.
- Database-level checks confirm that entries for `普通`, `我々`, `全て`, `一瞬`,
  `少年`, `殺さず`, `監視`, and `観察して` match the active annotation provider.
- Improved synchronization between pause/play and the background video. Further
  verification may still be needed if the app timer starts early or runs faster.
- Fixed Advanced Settings entry focus so entries no longer require an extra click
  after focusing another window.
- Selecting a `する`-capable stem checks sentence context: selecting `勉強` in
  `私は勉強した` becomes `勉強する` with `する-Verb`.
- A `する`-capable noun used as a noun, such as `勉強は楽しい`, remains `勉強`
  without the `する-Verb` tag.
- Hovering over the titlebar/close area of Settings or Advanced Settings hides the
  phone-mode subtitle handle.
- Moving the subtitle window in phone mode also moves its small handle.
- Removed or handled an extra unused window.
- Numpad hotkeys no longer fire while typing inside entries.
- Fixed ruby display for a Hitoribocchi subtitle near episode 7 at 04:57.
- The default skip value is saved.
- Advanced Settings no longer switches tabs unexpectedly.
- `Apply Now` no longer resets changed offset/skip entries to defaults.
- Pressing skip from an unchanged focused time entry keeps the previous value.
- Newly added local SRT files can be found during runtime.
- Decreasing from the first episode no longer selects the last cached episode.
- The episode number changes only after an episode is found.
- Season folders are not created unless a season is found.
- Fixed incorrect episode state when disabling or changing the selected episode.
- Slider duration updates correctly when offset or movie mode changes.
- New SRT selection updates the available SRT list.
- Switching to movie mode no longer retains the previous episode's maximum slider
  value.
- Subtitle window size is recalculated after changing files.
- Selecting an SRT after a remote session is more reliable.

## Additional Suggestions

- Add an `Undo last card` action that can safely remove the most recently added Anki
  note and its local Word Database entry before continuing playback.
- Add an episode vocabulary timeline showing where unknown, learning, and due words
  occur. Clicking a marker would seek directly to that subtitle.
- Add an adaptive pause mode that pauses only when a cue contains unknown or learning
  words, with a configurable delay before continuing.
- Add a three-cue Anki context option that includes the previous, current, and next
  subtitle while keeping the current cue visually emphasized.
- Add an offline dictionary cache manager with size information, last-used dates,
  and an option to prefetch dictionary entries for the current episode.
- Add per-anime presets for subtitle cleaning, Anki deck/tags, capture timing, voice
  target, and display style in addition to the existing offset memory.
- Add a subtitle-quality scan that reports overlapping cues, unusually long lines,
  malformed timestamps, encoding problems, and likely missing dialogue.
- Add a review-aware display mode that can dim mature words, emphasize due/learning
  words, and optionally pause only on words due for review.
- Add a session bookmark list for interesting subtitle moments, including timestamp,
  selected words, note status, and an optional comment.
- Add a lightweight shadowing mode that loops one cue, records the microphone, and
  plays source audio and the recording back-to-back without requiring online speech
  scoring.
