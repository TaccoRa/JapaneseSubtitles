1. Scope
Analyzed roots: `src/SubtitlePlayer` (SubtitlePlayer) and `anki_modify` (Modify_anki).

2. Project summary
SubtitlePlayer is a Tkinter desktop app that loads local or remote SRT/ASS subtitles, builds episode maps, renders ruby annotations on an overlay, and integrates with Anki via AnkiConnect plus optional translation APIs. It uses a controller-driven time loop and background downloads for remote subtitle caching.

Modify_anki is a set of CLI maintenance tools for Anki decks via AnkiConnect, covering front-field normalization, kanji image cleanup, duplicate reporting, stroke media injection, and missing stroke SVG synchronization with optional downloads from KanjiVG.

3. Architecture overview
- `src/SubtitlePlayer/app.py` bootstraps config, Tk root, startup thread, and UI/model/controller wiring.
- `src/SubtitlePlayer/controller/controller.py` coordinates input, playback time, episode changes, and Anki actions.
- `src/SubtitlePlayer/model/subtitle_manager.py` loads/cleans subs, parses SRT/ASS, builds episode maps, and downloads remote files.
- `src/SubtitlePlayer/model/anki_client.py` talks to AnkiConnect and translation services; manages deck/field routing.
- `src/SubtitlePlayer/model/renderer.py` draws subtitle/ruby layout onto a Tk canvas.
- `src/SubtitlePlayer/view/*` implements settings, overlay, popup, and loading UI elements.
- `src/SubtitlePlayer/utils.py` provides small time parsing/formatting and window dragging helpers.
- `anki_modify/modify_anki.py` is a multi-operation AnkiConnect CLI (normalize, cleanup, reports, strokes).
- `anki_modify/remove_kanji_images.py` removes redundant image tags in Front fields.
- `anki_modify/sync_missing_stroke_svgs.py` syncs KanjiVG SVGs into Anki media.

4. Execution flow
SubtitlePlayer:
1. `src/SubtitlePlayer/main.py` creates `SubtitlePlayerApp` and calls `run()`.
2. `SubtitlePlayerApp` loads `config.json`, builds a hidden Tk root, and shows a LoadingOverlay.
3. A background thread constructs `SubtitleManager`, loads subtitles, and computes total duration.
4. On success, UI windows (`SettingsUI`, `SubtitleOverlayUI`, `CopyPopup`) are created, then `SubtitleRenderer` and `SubtitleController` are wired.
5. Controller starts input listeners and schedules the update loop; Tk mainloop drives rendering and UI updates.

Modify_anki (all scripts follow this pattern):
1. Parse CLI args and build `http://{host}:{port}` base URL.
2. Validate AnkiConnect availability via `deckNames`.
3. `findNotes` and `notesInfo` gather target notes (with sort/limit/offset applied).
4. Build a plan/preview and print summaries (dry-run unless `--apply` for some scripts).
5. Apply changes with `updateNoteFields`/`addNote`/`storeMediaFile` as requested.

6. Key data structures and formats
- `display_data` in `SubtitleManager`: list of tuples `(clean_text, start_seconds, top_segments, bottom_segments)`.
- `subtitles`: list of `srt.Subtitle` objects; ASS files are parsed into the same structure.
- Episode maps: `remote_episode_map_global` (global index->item) and `remote_episode_map_season` (season->items).
- `github_search/*.json`: cached GitHub search results with repo metadata and subtitle item lists.
- `config.json`: JSON configuration controlling UI layout, timing, Anki fields, and remote settings.
- Advanced toggles: `SUBTITLE_AUTO_RUBY` (auto ruby generation) and `DISABLE_SPACE_HOTKEY` (disable space play/pause).
- `anki_reading_support/`: bundled MeCab/Kakasi binaries and dictionaries copied from the add-on.
- `unparsed_episode_names.tsv`: TSV log of filenames failing episode parsing.
- Modify_anki `PlanItem`: dataclass for note mutation plans (nid, old/new front, flags).
- AnkiConnect payloads: JSON `{action, version, params}` for find/update/add/media operations.
- Stroke media naming: `stroke_<codepoint>.svg` (5-hex Unicode codepoint).

7. Known issues and probable runtime errors
- `src/SubtitlePlayer/model/subtitle_manager.py:145` assumes local paths contain a `subs` folder; otherwise `.index('subs')` throws `ValueError` and startup can crash in local mode.
- `src/SubtitlePlayer/model/subtitle_manager.py:508` `get_total_duration` uses `self.subtitles[-1]`; empty/failed parses raise `IndexError`.
- `src/SubtitlePlayer/model/subtitle_manager.py:200` `srt.parse` exceptions are uncaught; malformed SRTs stop loading.
- `src/SubtitlePlayer/app.py:49` `ConfigManager("config.json")` is cwd-dependent; running from outside repo root fails.
- `src/SubtitlePlayer/utils.py:49` `parse_time_value` is ambiguous for short inputs (e.g., "90"), risking wrong seek times.
- `anki_modify/sync_missing_stroke_svgs.py:113` default behavior is APPLY, so missing media may be uploaded without explicit confirmation.
- Global input hooks (`pynput`, `pyautogui`) can fail on locked desktops or without accessibility permissions.
- Cache writes occur under `src/SubtitlePlayer/cache_github`; read-only installs will fail to download or log.

Subtitle parsing and timing checks:
- SRT parsing uses `srt.parse` (expects `HH:MM:SS,mmm`); dot-millis or malformed blocks may raise.
- ASS parsing supports `H:MM:SS.CS` or 3-digit fractions; unusual formats may be skipped.
- Auto ruby uses the bundled MeCab/Kakasi support binaries; if unavailable, subtitles remain unchanged.
- Time comparisons use floats from `total_seconds`; boundary cases can miss cues without epsilon in some paths.
- Sync drift risk: controller time is driven by wall-clock deltas, not by actual Chrome video time.

Chrome subtitle sync methods (pros/cons/hints):
1. Chrome DevTools Protocol — Pros: precise `video.currentTime`; Cons: requires remote debugging, may break DRM; Hint: launch Chrome with `--remote-debugging-port`, call `Runtime.evaluate`.
2. Browser extension content script — Pros: direct access to DOM/video; Cons: extension packaging/install; Hint: send currentTime via WebSocket/native messaging to the app.
3. User script + local HTTP/WebSocket — Pros: minimal setup; Cons: manual script install, CORS/security concerns; Hint: Tampermonkey injects a `setInterval` that POSTs `currentTime`.

Modify_anki safety checks:
- Writes happen via AnkiConnect `updateNoteFields`, `addNote`, and `storeMediaFile`; no direct SQLite writes detected.
- `modify_anki.py` and `remove_kanji_images.py` are dry-run by default; `sync_missing_stroke_svgs.py` is not.
- No built-in backup or transaction rollback; partial updates are possible on failures.

```python
def get_total_duration(self) -> float:
    subs = getattr(self, "subtitles", None) or []
    if not subs:
        return 0.0
    try:
        return max(sub.end.total_seconds() for sub in subs)
    except Exception:
        return 0.0
```

```python
def parse_time_value(time: str, last_subtitle=None) -> float:
    text = str(time or "").strip().lower()
    text = text.replace(" ", "").replace("s", "").replace(",", ".")
    if not text:
        return 0.0

    if ":" in text:
        parts = [p or "0" for p in text.split(":")]
        while len(parts) < 3:
            parts.insert(0, "0")
        h_s, m_s, s_s = parts[-3], parts[-2], parts[-1]
    else:
        if "." in text:
            int_part, frac = text.split(".", 1)
        else:
            int_part, frac = text, ""
        if int_part.isdigit() and len(int_part) <= 2:
            h_s, m_s, s_s = "0", "0", int_part
        elif int_part.isdigit() and len(int_part) <= 4:
            int_part = int_part.zfill(4)
            h_s, m_s, s_s = "0", int_part[:2], int_part[2:]
        else:
            int_part = (int_part if int_part.isdigit() else "0").zfill(6)
            h_s, m_s, s_s = int_part[:2], int_part[2:4], int_part[4:6]
        if frac:
            s_s = f"{s_s}.{''.join(ch for ch in frac if ch.isdigit())}"

    if "." in s_s:
        sec_int, frac = s_s.split(".", 1)
        sec = int(sec_int or 0)
        frac = ''.join(ch for ch in frac if ch.isdigit())
        frac_secs = float("0." + frac) if frac else 0.0
    else:
        sec = int(s_s or 0)
        frac_secs = 0.0

    h = int(h_s or 0)
    m = int(m_s or 0)
    m += sec // 60
    sec %= 60
    h += m // 60
    m %= 60
    return h * 3600 + m * 60 + sec + frac_secs
```

16. Working Notes (2026-04-08 YouTube-style seek)
- Keyboard second-skip (`go_back` / `go_forward`) is now buffered while a key is held: repeated presses accumulate into a pending delta instead of applying per event.
- On key release, the accumulated pending delta is applied once as a single seek step, matching YouTube-style buffered scrubbing behavior.
- Pending seek amount is displayed inline in the time text as `(+/-Ns)` while the key is held.
- Repeat generation now uses an internal hold loop (initial delay + repeat interval) and stops immediately on release to avoid OS key-repeat queue aftereffects.
- Time-entry defocus now clears focus to no widget (instead of transferring focus to Play).


17. Working Notes (2026-04-08 hold-threshold + focus hardening)
