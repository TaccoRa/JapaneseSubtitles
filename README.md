# JapaneseSubtitles

Creates japanese subtitles with given srt file.

## Layout

- `src/` - application code
- `anki_modify/` - AnkiConnect maintenance tools
- `dev/tests/` - pytest tests and manual UI test scripts
- `dev/experiments/` - prototypes, probes, profiling, and scratch data
- `docs/analysis/` - investigation notes and performance analysis
- `subs/` - local subtitle data used by `config.json`

For installation:
python -m venv venv
source venv/bin/activate  # or venv\Scripts\activate on Windows
pip install -r requirements.txt
